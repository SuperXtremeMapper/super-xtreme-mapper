# Editor design

Use the existing AppThemeV2 pro-audio interface: stone dark surfaces, warm amber selection and primary actions, semantic red for shared MIDI highlights. Authors inspect dense mappings in a music-production workspace; retain the established dark theme and compact layout.

System fonts at 11–12 points, monospaced MIDI/condition values, 4/8/12/16-point spacing. Use native accessible controls, explanatory help, and text/icon cues alongside color. Keep the table and inspector structure. New bulk previews use the existing sheet pattern for an explicit review/apply operation.
