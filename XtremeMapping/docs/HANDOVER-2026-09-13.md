## Critical bug fixes (root causes)
1. **"I couldn't read the answer" (parse failure).** The Anthropic API now injects an extra `"caller":{"type":"direct"}` key into tool-use inputs. `AssistantConversationService.decodeResponse` required an **exact** key set (`Set(input.keys) == ["answer","operations"]`), so it rejected valid replies. Fixed by switching to **presence** checks (the JSONDecoder already ignores extra keys). **If similar strict `Set(...keys) ==` checks exist elsewhere, they will break the same way.**
2. **Citation guardrail** rejected whole answers when a "fact" lacked a row cite. Now explanation replies **demote** uncited facts to interpretations; conversation path lets them through. Invented/out-of-file citations are still rejected.
3. **Truncation:** explanation service capped at 4096 tokens and decoded before checking `stop_reason`; raised to 8192 and added an early max_tokens check.
4. **IN/OUT/IN-OUT buttons** had a collapsing hit area (`Color.clear` with `maxWidth:.infinity` under `.fixedSize()`). Fixed with a full-size transparent Menu overlay while keeping the original styled visual + rollover.
