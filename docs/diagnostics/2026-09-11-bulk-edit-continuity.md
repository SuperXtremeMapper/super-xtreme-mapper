# Bulk edit continuity

## Current synthesis

Selection-scoped comment replacement and compatible Hotcue Type command changes share a snapshot-based preview plan. Literal find/replace supports case matching, empty replacement, affected-row counts and before/after text. Empty find is a no-op. Command choices are limited to the verified output family 2333–2340; no arbitrary substitutions are offered.

Applying validates every selected row and owning device before any mutation. Locked, missing, duplicate or changed rows cannot be partially applied. A single document mutation supplies Undo and Redo. Unselected edits remain intact.

Compatible imported Hotcue changes preserve opaque CMAD target/profile bytes. Explicit edits to other properties still use the established writer paths. Existing ordinary-save risk checks are retained. Native fixture inspection exposed dangling bindings and unmodeled frames; roundtrip testing therefore uses a serialized/imported Hotcue mapping, while an opaque-payload regression verifies exact preservation independently.

Parent integration owns launch actions and final native UI walkthrough. No open design questions. Do not compress this synthesis without human review.
