## Proposed integration

Keep provenance separate from coverage. Manufacturer evidence, Community template and My learned controls identify origin. Partial coverage/documentation only describes what is established. Preserve author, version, source URL, configuration requirements and evidence for each physical-control association.

A TSI identifies MIDI-to-Traktor assignments; physical labels require reliable comments, diagrams or hardware configuration files. A missing input or LED binding is not inferred from the opposite direction. Cross-check against existing manufacturer maps, quarantine conflicts, and run preservation/diagnostic checks before promoting entries. Check reuse terms before redistributing mapping packages.

In the later UI pass, a controller's optional template selector would distinguish Factory from a named community setup. Evidence details remain optional. Existing TSI imports continue through review; selecting hardware knowledge does not install someone else's performance mapping or change hardware settings.
