# Review priorities: DJ controllers first

User direction: finish the current integration batch, then prioritize DJ MIDI controllers over MIDI-enabled mixers. This is a planning view of the existing evidence catalogue, not a sales ranking or a claim of working MIDI support.

## Current 26-model integration batch

| Category | Models |
|---|---|
| DJ control surfaces | Allen & Heath K1/K2/K3; Pioneer DDJ-FLX4, FLX10, REV5, REV7; AlphaTheta DDJ-GRV6; Hercules Inpulse 500; Denon LC6000 |
| Standalone DJ systems / players with documented control modes | AlphaTheta OMNIS-DUO, XDJ-AZ, CDJ-3000X; Pioneer XDJ-RX3 |
| General performance / assignable controllers | Akai APC40 mkII and APC mini mk2; Faderfox UC4; Novation Launchpad Pro MK3, X, Mini MK3 and Launch Control XL 3 |
| MIDI-enabled mixers | Xone:96, Xone:92 Mk2, Euphonia, DJM-A9, DJM-S11 |

The MIDI-mode subset is the scope for standalone systems and players. Their native screens, audio features and host integrations are not automatically supported by a MIDI profile.
