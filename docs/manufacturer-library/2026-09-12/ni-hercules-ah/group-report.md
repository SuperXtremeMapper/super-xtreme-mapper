# Native Instruments, Hercules, Allen & Heath source library

Retrieved 2026-09-12. Manufacturer manuals and support sources only. DJUCED is Hercules/Guillemot’s own software site, explicitly linked from Hercules support. NI community evidence is restricted to the named NI employee’s accepted answer; other posts are not evidence. Model selection is representative, not a sales or popularity ranking. MX2 and Inpulse 200 MK3 were verified on current official pages; older requested models remain identified by exact generation.

Grades concern documentation available for extraction, never an app profile or hardware test. Original downloads and SHA-256 values are in each model manifest and downloads.json. PDFs are retained byte-for-byte with layout text derivatives; HTML is retained with text derivatives. Printed page numbers equal PDF page numbers unless stated. Existing K1/K2/K3 sources are referenced without duplicating originals.

## Recommended next profile work

1. Xone:92 Mk2: extract the three default CC controls and identify optional CC94 separately. Exclude realtime clock/start-stop from a simple Note/CC-only profile.
2. Xone:96: extract numeric send/receive matrix using human channel16; preserve USB output enable routing and which controls accept return data.
3. Inpulse 500: extract chart into an intermediate review table, converting zero-based channel nibbles explicitly. Preserve Shift and pad-mode state, paired tempo CCs, relative encoding and LED values. Resolve missing/conflicting rows before promoting any final map.
4. Existing K-series: reuse archived sources and existing app work. K3 factory and custom editor maps must remain distinct; avoid importing K2 layer assumptions into K1.
5. PX5: CC map can progress, but block numeric Note conversion pending official clarification or hardware capture of conflicting octave labels.
6. NI and remaining Hercules: acquire an official protocol/template or capture documented MIDI mode on hardware. Native Traktor behavior and software action tables alone are insufficient. S4 MK3 is excluded from generic MIDI profiling.

## Limits and retrieval failures

- Xone:96 owner PDF and separate MIDI PDF returned HTTP403. Official support HTML user guide and full numeric implementation table were retrieved; this is a format fallback, not an inaccessible model. Exact failures remain in downloads.json.
- Large Hercules manuals contain many languages; inspection targets the English controls and any MIDI sections, with full text retained for all pages.
- Current SXM schema supports note/controlChange; absolute7Bit, relativeTwosComplement and noteGate; base/amber/green layers; red/amber/green colors. Relative two’s-complement CC is already representable. High-resolution CC pairs, arbitrary modes/channels, richer RGB feedback, proprietary NHL/native operation and MIDI realtime need schema adaptation or explicit exclusions. Source extraction readiness does not establish current-schema compatibility. This archive changes no app features.
- Inpulse500 table anomalies and PX5 conversion inconsistencies are recorded rather than silently corrected. Hardware was not available/tested.
- Source files are manufacturer copyright; preserved here as research reference material. No redistribution license inferred.
