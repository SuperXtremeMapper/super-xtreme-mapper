# Manufacturer documentation library

[12 September 2026 collection report](2026-09-12/REPORT.md) · [Model/source index](2026-09-12/MODEL-INDEX.md) · [CSV catalogue](2026-09-12/catalogue.csv) · [JSON catalogue](2026-09-12/catalogue.json)

This archive supplies evidence for controller profiles and explanations. Documentation readiness is separate from implemented SXM support. Originals remain unchanged; extracted text is a search aid. Per-source URLs, SHA-256 hashes, document locators, retrieval failures and unresolved contradictions are retained.

Current collection: 68 model records, 15 manufacturers, 88 newly acquired PDF documents and existing K-series/Euphonia source references. See the report for exact scope and verification counts.

When adding evidence, identify exact model/generation and mode/template; retain original bytes, source URL, retrieval date and checksum; record send/receive independently; cite pages or sections for every extracted binding. Do not silently fix conflicting manufacturer tables or assume a documented MIDI mode establishes a complete address map.

Bundled application profiles remain separate from this research archive. Downloading a manual does not install a profile or configure hardware.
