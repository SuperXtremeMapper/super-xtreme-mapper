What you can do with it

  • ›Find by control — search "Play button", jump to the rows that use it.
  • ›Ask in plain words — the Assistant knows the hardware: "what does my K3 Play button do?"
  • ›Fix an address — if your unit differs, capture the real one with MIDI Learn as a saved override.
  • ›See what's unknown — partial / docs-only devices say which controls they can't identify.
  • ›Keep it — Export JSON retains the profile + overrides (TSI alone can't).
